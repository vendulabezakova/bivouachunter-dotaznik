# BivouacHunter — Dotazník uživatelského výzkumu

Dotazník vznikl jako součást uživatelského výzkumu pro aplikaci **[BivouacHunter](https://github.com/vendulabezakova/bivouachunter)** — nástroje pro hledání míst na bivakování v přírodě.

Výzkum je součástí kurzu **[UX v praxi: Navrhni aplikaci očima uživatelů](https://www.czechitas.cz/kurzy/ux-v-praxi-navrhni-aplikaci-ocima-uzivatelu)** organizovaného Czechitas.

---

## Co dotazník zjišťuje

- **Zkušenosti** — jak často respondenti chodí na túry a jaké mají zkušenosti s bivakováním
- **Geografie** — kde nejčastěji bivakují a jaké dálkové trasy absolvovali nebo plánují
- **Parametry místa** — důležitost jednotlivých faktorů při výběru místa na spaní (přístřešek, voda, orientace, vítr, srážky, odlehlost...)
- **Aplikace** — které mapové a počasí aplikace používají při plánování a přímo v terénu
- **Bolestivé momenty** — co jim v současných aplikacích chybí a jaké nepříjemné situace v terénu zažili
- **Technické preference** — iOS vs. Android, důležitost offline funkčnosti
- **Zájem o produkt** — zda by podobnou aplikaci stáhli

---

## Technologie

Dotazník je postaven jako jednoduchá statická stránka bez externích závislostí.

- **HTML / CSS / JavaScript** — čistý frontend, žádný framework
- **Google Fonts** — DM Sans, DM Mono
- **localStorage** — odpovědi se ukládají lokálně v prohlížeči
- **GitHub Pages** — hosting
